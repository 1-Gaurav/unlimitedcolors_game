Unlimited Background Color Changer 🎨

A simple project that changes the background color every time you click on the page.  
Built using **HTML, CSS, and JavaScript**.

 🚀 Features
- Click anywhere on the screen to change the background color.
- Generates unlimited random colors.
- Lightweight and fast (only frontend, no backend).

---
 🛠️ Tech Stack
- **HTML5**
- **CSS3**
- **JavaScript
